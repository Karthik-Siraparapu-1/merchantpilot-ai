# Contributing to MerchantPilot AI

Thank you for your interest in contributing to MerchantPilot AI! We welcome contributions from developers, designers, and AI researchers.

## How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/your-username/merchantpilot-ai.git
cd merchantpilot-ai
pnpm install
```

### 2. Create a Feature Branch
```bash
git checkout -b feat/my-new-ai-agent
```

### 3. Development Workflow
- **Frontend (Web):** Next.js 16 + TailwindCSS + Lucide Icons + Framer Motion.
- **Backend (API):** NestJS + Prisma ORM + PostgreSQL + Redis.
- Always run `pnpm typecheck` and `pnpm lint` before opening a PR.

### 4. Code Style & Commit Convention
We follow conventional commit specifications:
- `feat(scope)`: A new feature
- `fix(scope)`: A bug fix
- `docs(scope)`: Documentation changes
- `refactor(scope)`: Code refactoring without functionality changes

### 5. Submit Pull Request
Push your branch to GitHub and create a Pull Request detailing your changes, test results, and visual screenshots.
