## [1.0.0] - 2026-09-05

### Added
- **Named AI Digital Workforce**: Athena, Atlas, Vega, Sentinel, Pulse, Orion, Nova.
- **Multi-Agent Debate Engine**: Deliberative decision making with executive consensus verdicts.
- **AI Executive Briefing & Command Center**: Macro telemetry, business health score (95/100), and ₹82k opportunity cards.
- **Hands-Free Voice AI Assistant**: Web Speech API integration with wake-phrase detection, interruption, and context memory.
- **Business Digital Twin Sandbox**: Scenario lab with Monte Carlo price elasticity simulations.
- **AI AutoPilot Governance Center**: Per-domain autonomy levels (`Manual`, `Semi-Auto`, `Fully Autonomous`).
- **AI Trust & Transparency Center**: Real-time decision accuracy, sub-second latency, and audit verification.
- **Deterministic Action Rollback**: 1-click undo capability for all automated state mutations.
- **AI Agent Marketplace**: Plugin architecture for 3rd party specialized domain agents.
- **26 Production Next.js Routes**: Comprehensive e-commerce management suite.
